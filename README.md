## 🚀 Featured Project

### [BookNook — Neighborhood Book-Sharing Platform](https://booknook-frontend-orpin.vercel.app/)

A community library where readers can share books, discover titles to borrow, and manage their own collections.

- Browse a community shelf and view book details and availability.
- Add books with titles, authors, categories, descriptions, cover images, and copy counts.
- Manage a personal collection and follow borrowing activity.
- Responsive experience for desktop and mobile.

[Live Site](https://booknook-frontend-orpin.vercel.app/) · [Frontend Repository](https://github.com/1sababtonoy1/book-nook-frontend) · [Backend Repository](https://github.com/1sababtonoy1/book-nook-backend)
